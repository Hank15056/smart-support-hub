# Smart Support Hub

Веб-платформа внедрения и сопровождения программного продукта. Команда поддержки ведёт в ней внедрения у заказчиков, регистрирует инциденты, контролирует сроки SLA, принимает заявки на изменения и планирует новые версии.

Учебный проект · Павлов А.С., группа КС 3-24.
Все организации, люди и данные в проекте вымышленные.

**Сайт:** https://hank15056.github.io/smart-support-hub/

## Возможности

| Страница | Что умеет |
|---|---|
| Панель (`index.html`) | 4 показателя: активные внедрения, открытые инциденты, процент выполнения SLA, текущая версия; графики «Инциденты по приоритетам» (bar) и «Заявки по видам сопровождения» (doughnut) |
| Внедрения (`deployments.html`) | список внедрений с этапом и процентом готовности, добавление внедрения, отметка выполненных задач |
| Инциденты (`incidents.html`) | регистрация инцидента с проверкой поля, приоритет, статус, срок и состояние SLA, фильтр по статусу, перевод в работу и решение |
| Заявки (`maintenance.html`) | заявки четырёх видов сопровождения, статус и целевая версия |
| Релизы (`releases.html`) | история версий и изменений, подсказка номера следующей версии (patch / minor / major) |

Дополнительно: светлая и тёмная тема с сохранением выбора, адаптивная вёрстка (1366, 768 и 390 px), кнопка «Сбросить учебные данные».

## Сроки SLA

| Приоритет | Срок решения |
|---|---|
| critical | 4 часа |
| high | 8 часов |
| medium | 24 часа |
| low | 72 часа |

## Технологии

HTML5, CSS3 (Grid, Flexbox), JavaScript, localStorage, Chart.js 4 (через CDN), Git / GitHub Pages.

## Запуск

Откройте папку в VS Code и запустите `index.html` через расширение **Live Server** (или любой локальный HTTP-сервер). Для графиков нужен интернет: Chart.js загружается с CDN.
